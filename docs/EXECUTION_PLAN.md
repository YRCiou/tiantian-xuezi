### 2.3 每單元 7 關(發音、聽力、認讀、字詞、語句、寫字、考核)

| # | key | 名稱 | 玩法 | 計分 |
|---|---|---|---|---|
| 1 | `learn` | 學一學 | 現有字卡逐字認讀 + 語音跟讀(卡片加「🗣️ 跟著唸」按鈕,播完提示長輩開口唸一次) | 看完即 100 分 |
| 2 | `listen` | 聽聲音 | 現有:聽音選字 8 題 | 首次答對題數 ÷ 題數 × 100 |
| 3 | `look` | 看圖選字 | 現有:看圖+例詞選字 8 題 | 同上 |
| 4 | `word` | **詞語練習(新)** | 例詞挖空選字 8 題:顯示「（　）飯」念「吃飯」,三選一 | 同上 |
| 5 | `sentence` | 句子填空 | 現有:例句挖空 8 題 | 同上 |
| 6 | `write` | 寫一寫 | 現有描字;**最後 2 字改聽寫**:先聽音在 3 個字中選對,再描寫 | 全部完成 100 分;聽寫選錯每字 -10 |
| 7 | `utest` | **單元小考(新)** | 10 題綜合:聽力 2 + 看圖 2 + 詞語 3 + 句子 3,每題 10 分 | 首次答對 × 10 |

- **每一關 ≥ 60 分才算過**;關卡在單元頁依序排列,前一關 ≥ 60 才開下一關
  (現況是隨時可點任何關,要加上關內順序鎖)。
- `utest` < 60 分:結算頁只給兩個按鈕「🔁 回去學一學複習」(導向 `/unit/:id/learn`)與
  「📋 回單元」,語音鼓勵「再複習一次,一定可以的!」;**不開放下一單元**。
- 單元解鎖規則:`unitUnlocked(n)` = 單元 n−1 的 `utest ≥ 60`,
  且若 n−1 是 5 的倍數,還需要總複習關 `R(n−1) ≥ 60`。

### 2.4 總複習關(每 5 單元)

- 位置:單元 5、10、15、…、40 完成後出現(路由 `/review/5`、`/review/10`…)。
- 題目**程式動態產生**,不寫死資料:12 題 = 最近 5 個單元每單元抽 2 題(聽力/詞語/句子隨機)
  + 從更早所有單元隨機抽 2 題(單元 5 的 R5 沒有更早內容,就 10 題)。
- 每題 100/題數 分,≥ 60 過;不過則提示回去複習,並將答錯的字加入複習箱。

### 2.5 季檢定(新資料檔 qexam.js)+ 年末模擬考

- 每季末 1 回,10 題,格式與 `exam.js` 的 EXAMS 完全相同(`t/q/say/opts/a`),
  題目**原創**、只考該季 10 單元出現過的字;≥ 60 過。
- 解鎖:該季 10 單元 utest 全部 ≥ 60 且 2 個總複習關 ≥ 60。
- 下一季第一個單元(11、21、31)解鎖需要上一季季檢定 ≥ 60。
- 年末 3 回模擬考(現有 EXAMS):解鎖條件改為「4 回季檢定都 ≥ 60」,通過標準維持 80 分。

### 2.6 錯字複習箱(spaced-repetition 簡化版)

- 任何測驗第一次就答錯的目標字 → `data.reviewBox[字] = { miss: 次數, last: 日期 }`。
- 首頁今日任務邏輯:若複習箱有 ≥ 5 個字,今日任務優先顯示
  「🔁 複習一下(N 個字)」→ 路由 `/review-box`:對這些字出聽音選字 + 描寫,
  答對一次 `miss - 1`,`miss` 歸零就移出箱子。做完才顯示正常的下一關任務。
- 複習箱永遠可從首頁新選單卡「🔁 錯字複習」進入(箱子空時顯示「沒有要複習的字,真棒!」)。

## 3. 內容產製流程(Phase 3 的施工法)

### 3.1 選字來源(只取「字表」這種事實資料)

1. **教育部成人基本識字教材**(6 冊分級:初一/初二/中一/中二/高一/高二):
   https://depart.moe.edu.tw/ED2400/News_Content.aspx?n=84EAABCC9E60E20A&sms=192DA19CAF96AADC&s=07CAACC2E475F98A
   PDF 很大(13~38 MB),**不要下載整本**;用它已公開的分級與生活主題架構
   (本企劃 §2.2 主題表已對齊)作為單元主題與難度分級依據。
2. **教育百科「生字詞彙表」**(南一/康軒/翰林 各版本、各年級生字,結構化網頁,可直接 WebFetch):
   `https://pedia.cloud.edu.tw/Bookmark/Textword?year=110_1&degree=1&subject=國語&press=翰林版`
   參數:`degree`=年級、`press`=`南一版|康軒版|翰林版`、`year`=學年度_學期。
   抓 **一、二年級,三版本、上下學期** 的生字集合。
3. **教育部 4808 常用字表**(驗證每個選字都是常用字):
   https://language.moe.gov.tw/material/info?m=9fe3ff5a-5a8c-4817-9e60-6337dd55a509
4. 備援:若教育百科抓取失敗,改用新北市教育局「生字語詞簿」公開 PDF
   (搜尋「新北市 生字語詞簿」),或以教育部字頻表高頻字遞補。

### 3.2 選字演算法

```
候選池 = (三版本一二年級生字聯集) − (現有 127 字)
優先序 = 出現於 ≥2 個版本 > 單一版本;同分依主題契合度
每單元 10 字:從候選池挑「與該單元主題直接相關」的字;
主題字不足時,以該主題常用詞中的高頻字補足(仍須在 4808 常用字內)。
全 40 單元字不得重複(寫驗證腳本檢查,見 §3.4)。
```

### 3.3 著作權紅線(必守)

- 只擷取「某字在某年級教過」這類**事實性字表**;
- **例詞、例句、題目全部原創**,以長輩生活情境撰寫,不得抄任何課本課文、習作句子;
- 模擬考維持「仿題型、原創題目」的現行做法。

### 3.4 每字資料規格與自動驗證

每個 item 欄位(舊 127 字也要補齊 `words`):

```js
{ w:"藥",           // 單一繁體字,全課程唯一
  zy:"ㄧㄠˋ",       // 注音含調號(一聲不標)
  e:"💊",           // 圖案;抽象字可用相關情境 emoji
  word:"吃藥",      // 主例詞(2~3 字,含 w,看圖選字用)
  words:["吃藥","藥局"], // 新增:2~3 個詞,詞語練習用,每個都含 w
  s:"飯後要記得吃藥。" } // 原創生活例句,必含 w,12 字以內
```

**新增 `scripts/validate-data.js`(Node,無相依套件)**,Phase 3 每寫完一季就跑一次:

1. 全部單元 `w` 無重複;`s` 包含 `w`;每個 `words[i]` 包含 `w`;`word === words[0]`。
2. `zy` 只含注音符號與調號 `ˊˇˋ˙`。
3. 所有文字欄位不得含 `'`、`\`、`<`、`>`、`&`(app.js 用 inline onclick + esc(),半形單引號會炸)。
4. 每單元 items 數 8~13;40 單元皆有 4 個以上 phrases。
5. qexam 每回恰 10 題、`a` 在 0~3、選項 4 個且不重複、`聽` 題必有 `say`。

執行:`node scripts/validate-data.js`,全綠才准 commit。
