# 天天學字 📖

給 65 歲以上長輩的繁體中文識字網站。重點是**生活識字**——
長輩早就會「說」,這裡幫他們把每天說的話,一個字一個字「認」回來。

## 課程結構

**主課程:四季 40 單元、423 個字、一整年的份量**

| 季 | 單元 | 主題 |
|---|---|---|
| 1 生活入門 | 1–10 | 數字錢幣、時間、家人、吃喝、路上標示、買東西、搭車、健康、天氣、常用會話 |
| 2 出門辦事 | 11–20 | 看醫生、銀行郵局、電話、填表格、市場、超市、地址、捷運、公家機關、告示 |
| 3 家庭與健康 | 21–30 | 煮飯、家事、衣物、住家、身體部位、生病、運動、健康飲食、牙齒眼睛、緊急求助 |
| 4 社會生活 | 31–40 | 節慶、拜拜、婚喪喜慶、鄰居、電視廣播、種植、旅遊、水電帳單、書信、活到老學到老 |

**每個單元 8 關**,發音、聽力、認讀、字詞、語句、朗讀、寫字、考核全部兼顧:

1. 📖 學一學(字卡 + 跟著唸)
2. 🎧 聽聲音(聽發音選字)
3. 🖼️ 看圖選字(只給圖與聲音,不給答案)
4. 🧩 詞語練習(把詞語補完整)
5. ✏️ 句子填空
6. 📢 讀一讀(朗讀短文 + 短文填空)
7. ✍️ 寫一寫(描字 + 聽寫)
8. 🏁 單元小考(10 題綜合)

**評量與複習**

- 每一關都打分數,**60 分才過關**;小考不到 60 分會被帶回「學一學」重新複習
- 每 5 個單元一次**總複習關**(動態出題,含更早學過的字),過關才能繼續
- 每季末一次**季檢定**(10 題,60 分過),通過才進下一季
- 🎓 **檢定挑戰**:仿全民中檢(初等)的 3 回模擬考,80 分通過
- 🔁 **錯字複習箱**:答錯的字自動收集,累積 5 個就會出現在「今天的任務」

## 學得快也不會沒事做 🎲

主課程之外有**永遠玩不完**的練習區,學完第一課就全部開放:

- 📅 **每日挑戰**:每天一組 10 題,題目從學過的字動態產生,天天不重複
- 🗼 **闖關塔**:無限層,越高層題目越多、選項越多、題型越難
- 📢 **朗讀練習室**:所有學過的短文與生活常用句,隨時可以練發音
- 🔁 **錯字複習**:針對個人弱點的複習

模擬考也只要**通過任一季的季檢定**就開放,不必等到全部學完。

## 其他特色

- 🧩 **注音是補充教材**:注音符號表與注音闖關隨時可玩,想練發音就去,不會擋住識字進度
- **每天一點點**:首頁「今天的任務」、連續學習 🔥、集章月曆、24 種徽章
- **滿滿的鼓勵**:答對有拍手聲、彩帶、語音讚美;答錯只有溫柔提示,不扣分
- **給長輩的介面**:超大字體按鈕、高對比、每頁 🔊 語音說明(不識字也能用)
- **免登入**:自動產生 6 碼「學號」,換裝置輸入學號即可找回進度
- **每個選單獨立網址**:`/units`、`/unit/3/read`、`/daily`、`/tower`、`/reading`、`/box`…

## 技術

- 純前端 Vanilla JS SPA(無建置步驟),History API 路由 + `_redirects` fallback
- 語音:瀏覽器內建 `speechSynthesis`(zh-TW);音效:Web Audio 合成拍手/叮咚
- 部署:Cloudflare Pages;進度:localStorage + Pages Functions + Cloudflare KV
- 舊版(星星制)進度會自動遷移成百分制,老學員的進度不會倒退

## 開發

```bash
npx wrangler pages dev public    # 本機開發(含 API 與 KV)
node scripts/validate-data.js    # 改課程內容後一定要跑
npx wrangler pages deploy public # 部署
```

## 加新內容的規則

改 `units*.js` 之後**一定要跑 `node scripts/validate-data.js`**。它會擋下:

- 重複的字、例句沒有包含目標字、詞語沒有包含目標字
- 注音格式錯誤、缺 emoji、短文或填空題格式不對
- 文字裡有 `'` `"` `\` `<` `>` `&`(會打壞 inline onclick,整頁當掉)
